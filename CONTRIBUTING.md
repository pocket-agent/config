# Contributing

Thanks for contributing to **config** — part of the [Pocket Agent](https://github.com/pocket-agent) ecosystem.

## Changes

- **`modules.yaml`** — new sibling repos, paths, or install flags
- **`setup.defaults.yaml`** — default connection profile for fresh installs

Do not commit `user-setup.yaml` (local per machine).

## Pull requests

1. Branch from `main`.
2. Keep changes focused.
3. Update this repo's `CHANGELOG.md` for user-visible changes.
